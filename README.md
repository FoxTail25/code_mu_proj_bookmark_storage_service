# 📑 Bookmark Storage Service

> **[🌐 Открыть живую версию сервиса на GitHub Pages]([https://github.io](https://foxtail25.github.io/code_mu_proj_bookmark_storage_service/)**

Веб-приложение для удобного хранения, категоризации и структурирования пользовательских закладок. Проект выполнен в рамках персонального практического задания повышенной сложности от ментора **Дмитрия Трепачёва (Code Mu)**.

Главный фокус проекта — проектирование удобного UX/UI для быстрого доступа к ссылкам и управление комплексным клиентским состоянием (State Management).

---

## 🚀 Основной функционал

*   🗂️ **Кастомизируемые категории:** Пользователь может самостоятельно создавать, редактировать и удалять папки/категории для сортировки ссылок.
*   🔗 **Управление закладками:** Быстрое добавление ссылок с валидацией URL, присвоением кастомного имени и привязкой к категориям.
*   ⚡ **Эргономичный UX:** Проработанный интуитивный интерфейс для мгновенного поиска и перехода по сохраненным ресурсам.
*   💾 **Persistent Data:** Все данные пользователя (категории и структура закладок) автоматически синхронизируются и сохраняются в `localStorage`, что исключает их потерю при перезагрузке страницы.

---

## 🛠️ Технологический стек

*   **Core:** Vue 3 (Composition API)
*   **State Management:** Pinia (модульная архитектура хранилищ)
*   **Routing:** Vue Router
*   **Styles:** Bootstrap 5.3 (адаптивная сетка, готовые UI-компоненты)
*   **Build Tool:** Vite

---

## 🎨 Архитектурные особенности проекта
*   Логика работы с хранилищем закладок полностью вынесена в изолированные реактивные store-модули на **Pinia**.
*   Интерфейс спроектирован по методологии компонентного подхода Vue, разделяя логику отображения списков, форм добавления и элементов навигации.
